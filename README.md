## 🌟 Key Highlights & Features

- **Spatial Floating Product Stage**:
  - Isolated hyper-luxury 3D product subjects floating in mid-air with soft continuous levitation physics (`y: [0, -12px, 0]`) and realistic 3D floor shadows.
  - **Zero Square Box Borders**: Organic elliptical radial gradient alpha masking feathers each piece seamlessly into the dark atmosphere.
- **Alternating Scroll Progression (Left $\longleftrightarrow$ Right Rhythm)**:
  - `Suite 01`: **Living Room Suite** — Text Left $\longleftrightarrow$ Floating Sovereign Sofa Right.
  - `Suite 02`: **Master Bedroom Suite** — Floating Imperial Bed Left $\longleftrightarrow$ Text Right.
  - `Suite 03`: **Royal Dining Suite** — Text Left $\longleftrightarrow$ Floating Sintered Stone Dining Right.
  - `Suite 04`: **Executive Study Suite** — Floating Presidential Desk Left $\longleftrightarrow$ Text Right.
  - `Suite 05`: **Bespoke Atelier Suite** — Text Left $\longleftrightarrow$ Floating Handcrafted Joinery Right.
- **5 Dedicated Environmental Color Shades**:
  - Dynamically morphs ambient lighting and background gradients per suite:
    - *Living*: Deep Obsidian-Teal (`#121F24`) + Amber Glow
    - *Bedroom*: Midnight-Indigo (`#1B182B`) + Champagne Wood Glow
    - *Dining*: Emerald-Obsidian (`#10261E`) + Calacatta Gold Spotlight
    - *Executive*: Havana Cognac (`#29170E`) + Tuscan Leather Aura
    - *Bespoke*: Ancient Seasoned Amber (`#241D12`) + Artisan Rays
- **Interactive Bespoke Studio Configurator**:
  - Real-time furniture customizer (Room selection, Timber species, Fabrics, Width/Depth sliders) generating instant WhatsApp inquiry payloads.
- **Direct WhatsApp Concierge Deep-Linking**:
  - Every CTA routes directly to `+880 1960-481983` with pre-filled product specs and material details.

## 🚀 Quickstart & Local Development

### 1. Clone the repository
```bash
git clone https://github.com/AlfazMahmudRizve/heaven-furniture-atelier.git
cd heaven-furniture-atelier
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 4. Run automated test suite
```bash
npm test
```

### 5. Production build
```bash
npm run build
```
